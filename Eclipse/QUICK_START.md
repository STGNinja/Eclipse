# 🎯 Quick Start Guide - New Features

## What's New?

### 1. 🧠 Artifacts - AI Memory System
**What it does:** Eclipse now remembers important things you tell it!

**Try it:**
- Say: "My name is Sarah and I love coffee"
- See the "Saved to Artifacts" notification pop up
- Tap the Artifacts button in the sidebar to see all saved info
- Eclipse will remember this in future conversations!

**Access:** Sidebar → Artifacts (brain icon)

---

### 2. 📅 Real Calendar Integration
**What it does:** Eclipse can now actually create events in your Apple Calendar!

**Try it:**
- Enable it: Settings → Capabilities → Apple Calendar (ON)
- Say: "Schedule a dentist appointment tomorrow at 10am"
- Eclipse creates it and you'll see: "✅ Event created successfully!"
- Open your Calendar app - the event is there!

**Supported phrases:**
- "Create a meeting..."
- "Schedule..."
- "Add to my calendar..."

---

### 3. 🖼️ Profile Picture Updates
**What it does:** Your profile picture now actually updates and saves!

**Try it:**
- Go to Settings → Profile
- Tap the pencil icon on your profile picture
- Choose a new photo
- Watch it upload and update everywhere!

---

### 4. 💎 Liquid Glass Design
**What it does:** Beautiful new glass-like buttons and elements!

**See it:**
- Profile view buttons
- Settings elements
- Modern, fluid design throughout

## 🚨 First Time Setup

1. **For Calendar:**
   - Settings → Capabilities → Enable "Apple Calendar"
   - Grant permission when prompted

2. **For Artifacts:**
   - Just start chatting! Auto-detects important info
   - Or manually tap Artifacts to explore

3. **For Profile Photo:**
   - Go to Profile view
   - Tap pencil icon
   - Select photo
   - Wait for upload

---

## 💡 Pro Tips

**Artifacts:**
- Use trigger words like "remember that", "my favorite", "I prefer"
- Check Artifacts view to see what's saved
- Delete old/incorrect artifacts anytime

**Calendar:**
- Be specific with dates: "tomorrow", "next Monday", "Friday"
- Include time: "at 3pm", "at 15:00"
- Eclipse defaults to 1-hour events

**Profile:**
- Use high-quality photos for best results
- Photo is compressed but still looks great
- Updates instantly once uploaded

---

## ❓ Troubleshooting

**Artifacts not saving?**
- Try using trigger words: "remember", "my favorite", etc.
- Check Firebase connection in console logs

**Calendar not creating events?**
- Enable in Settings → Capabilities
- Check Calendar app permission in iOS Settings
- Make sure you said a clear date/time

**Profile photo not updating?**
- Check internet connection
- Wait for upload to complete
- Force quit and reopen app
